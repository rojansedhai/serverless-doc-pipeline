Multi-Tenant Security Architecture

Layered zero-trust controls across the serverless stack

Cryptographic Identity Propagation
Client tenant identity is extracted strictly from the verified Cognito JWT token claim (custom:tenant_id). User-supplied URL or body tenant parameters are ignored.
Dedicated AWS KMS CMK Encryption
Both S3 object storage and DynamoDB tables are encrypted at rest with automatic key rotation via Customer Managed Key.
Least-Privilege Scoped IAM Roles
Presigned URL Lambda is restricted to uploads/*. Document Processor Lambda is restricted to reading uploads/* and writing processed/*.
Enforced TLS & S3 Bucket Policies
S3 Bucket policy strictly denies all non-TLS requests (aws:SecureTransport = false) and blocks all public ACLs.

AWS Serverless Architecture Mapping

1. Amazon Cognito: Issues signed JWT tokens with tenant partition metadata.

2. API Gateway HTTP API (v2): Performs sub-millisecond JWT authentication and proxies to Lambdas.

3. Amazon S3 Storage: Direct browser-to-S3 presigned PUT uploads, KMS envelope encrypted.

4. Amazon EventBridge: Decoupled event bus filtering ObjectCreated notifications.

5. AWS Lambda OCR Worker: Extracts invoice fields, watermarks PDF, writes to processed folder.

6. Amazon DynamoDB: Single-table partition design with Global Secondary Indexes for tenanted querying.
